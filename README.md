# ranamihir.com

[![CI](https://github.com/ranamihir/ranamihir.github.io/actions/workflows/ci.yml/badge.svg)](https://github.com/ranamihir/ranamihir.github.io/actions/workflows/ci.yml)

Source for [ranamihir.com](https://ranamihir.com), the personal site of Mihir Rana.
A single static page with dark (default), light, and match-device themes, an
interactive terminal, and very little JavaScript.

## Tech

- **[Astro 7](https://astro.build)**: static output, responsive AVIF/WebP images
- **[Tailwind CSS 4](https://tailwindcss.com)**: CSS-first design tokens in `src/styles/global.css`
- **Fraunces** (display serif) + **Inter** (body), self-hosted via Fontsource
- **TypeScript** (strict), **Vitest**, **Prettier**
- Hosted on **GitHub Pages**, built and deployed by GitHub Actions

## Development

Requires Node 22.23.4 or newer (`.nvmrc` pins 24).

```bash
npm ci
npm run dev           # http://localhost:4321
npm run build         # static build → dist/
npm run preview       # serve the production build
npm run check         # type-check (astro check)
npm test              # unit tests (Vitest)
npm run format        # Prettier (format:check in CI)
```

## Layout

```
src/
  data/         all copy: site.ts, experience.ts, projects.ts
  components/   page sections (Hero, Experience, Projects, Terminal, Footer, Nav)
  lib/          logic with no markup: terminal shell, theme, text formatting, email
  layouts/      <head>, metadata, theme bootstrap
  pages/        index, 404, robots.txt
  assets/       images processed by Astro (portrait)
  styles/       global.css: tokens, dark theme, shared primitives
public/         files served as-is (icons, social card, project demos)
scripts/        brand-assets.py: regenerates icons and the social card
tests/          Vitest suites for src/lib
```

## Editing content

All copy lives in `src/data/`, separate from layout.

- **Inline formatting** in bios and write-ups: `**bold**` and `[text](https://…)`
  links (`src/lib/text.ts`).
- **The terminal** reads the same data, so new jobs, projects, and schools show
  up there (with Tab completion) automatically. Coursework appears only in the
  terminal.
- **Portrait**: replace `src/assets/portrait.jpg` with a 4:5 image. Strip its
  metadata first (phone photos carry GPS coordinates); Astro also strips it
  from the sizes it generates.
- **Project demos**: put the file in `public/projects/` and set `media` on the
  project. Prefer animated WebP over GIF, plus a still `poster` for visitors
  who prefer reduced motion.
- **Icons and social card**: `scripts/brand-assets.py` (see its docstring)
  regenerates `favicon.svg`, `favicon.ico`, `apple-touch-icon.png`, and
  `og-image.jpg` from the site's fonts and colours.

## Security

GitHub Pages can't set response headers, so the Content Security Policy ships
as a `<meta>` tag generated by Astro (`security.csp` in `astro.config.mjs`):
scripts and styles load only from the site itself or by hash, with no
`unsafe-inline`. Keep markup free of inline `style=""` attributes and
`is:inline` scripts. The one exception, the theme bootstrap in
`src/lib/theme-init.ts`, is hashed in the config.

The email address is XOR-encoded at build time and decoded in the browser
(`src/lib/email.ts`) to keep it away from scrapers that read raw HTML.

## Deployment

`.github/workflows/ci.yml` checks formatting, types, tests, and the build on
every push and pull request; pushes to `main` then deploy to GitHub Pages. It
also rebuilds on 1 January so the footer year stays current.

The custom domain is set under **Settings → Pages** (with **Enforce HTTPS**),
with DNS `A` records for `@` pointing at GitHub Pages and a `CNAME` for `www`.
`site` in `astro.config.mjs` drives canonical URLs, the sitemap, `robots.txt`,
and social-preview URLs.
